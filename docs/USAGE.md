# Инструкция: от установки до отфильтрованного списка

Это шаги по порядку — от пустой машины до команды, которая печатает
список треков нужного жанра. Если что-то уже сделано (например, Go
и Docker уже стоят) — просто пропусти этот пункт.

Рассчитано на то, что запускаешь всё у себя на компьютере (Windows,
PowerShell) — так и разрабатывался проект. На Linux/macOS команды те же,
только пути и разделители папок пиши на свой лад.

---

## 0. Что нужно установить заранее

- **Go 1.24+** — https://go.dev/dl/
- **Docker Desktop** (с плагином compose, он идёт вместе с ним по
  умолчанию) — https://www.docker.com/products/docker-desktop/
- **Chrome или Яндекс.Браузер** — с расширением работают оба.
- Бесплатный **ключ Last.fm API** — получить за минуту на
  https://www.last.fm/api/account/create (нужен для шага 6, определения
  жанров). Просто заполни форму, ссылки на сайт или приложение не
  нужны — впиши что-нибудь вроде своего GitHub.

Если ты в России — учти: Last.fm блокирует и сайт, и сам API для
российских адресов на уровне сервера (подтверждено эмпирически, Р-017
в `docs/DECISIONS.md`). Всё дальнейшее (кроме сбора треков из ВК —
это не касается) требует включённого VPN, который заворачивает весь
трафик компьютера, а не только браузер.

## 1. Установить расширение браузера

Расширение забирает список треков со страницы ВК прямо из твоей
залогиненной вкладки — без паролей, токенов и отдельного браузера.

1. Открой `chrome://extensions` (в Яндекс.Браузере — тот же адрес).
2. Включи "Режим разработчика" (переключатель в правом верхнем углу).
3. Нажми "Загрузить распакованное расширение".
4. Укажи папку `extension/` внутри склонированного репозитория (там,
   где лежит `manifest.json`).

Иконка появится в списке расширений — закреплять её на панель не
обязательно, оно работает автоматически на страницах `vk.com`/`vk.ru`.

Подробности и что делать, если ВК поменяет формат ответа, — в
[extension/README.md](../extension/README.md).

---

## 2. Собрать список треков со страницы ВК

1. Открой в браузере страницу с музыкой, например
   `https://vk.ru/audios12345678` — своей или того, чью библиотеку
   хочешь отфильтровать.
2. В правом нижнем углу появится панель "Tulle Music Genre Filter — сбор
   треков". Нажми "Начать сбор" — расширение само докрутит список до
   конца (это может занять пару минут на большой библиотеке).
3. Когда счётчик перестанет расти, сбор остановится сам (или останови
   раньше кнопкой "Остановить" — найденное не потеряется).
4. Нажми "Скачать JSON" — браузер сохранит `tracks.json` в папку
   загрузок.

## 3. Подготовить проект

Один раз при первой установке:

```powershell
git clone https://github.com/tulle-32/Pet_Project_3_Music_Genre_Filter.git
cd Pet_Project_3_Music_Genre_Filter

# Настройки: скопировать образец и заполнить
```

## 4. Поднять базу данных

**Это нужно делать каждый раз, когда садишься работать заново** — не
только один раз при установке. Контейнер с базой не запускается сам
при перезагрузке компьютера.

```powershell
docker compose up -d
docker compose ps    # дождись, пока в колонке STATUS появится healthy
```

Если Docker Desktop не запущен — сначала открой его, иначе команды
дальше будут падать с ошибкой вида `dial tcp ... connection refused`.

При первой установке — накатить схему и залить справочник жанров:

```powershell
go run ./cmd/music db up
go run ./cmd/music seed genres
```

## 5. Загрузить треки в базу

```powershell
go run ./cmd/music import file C:\путь\к\tracks.json --library "Имя библиотеки"
```

Имя библиотеки придумываешь сам — используешь его дальше во всех
командах (`enrich`, `filter`, `stats`). **Пиши его одинаково каждый
раз, вплоть до регистра букв** — `"Рус-Лан"` и `"Рус-лан"` для базы
это две разные библиотеки. Проверить, что уже есть:

```powershell
go run ./cmd/music library list
```

Повторный импорт того же файла (или обновлённого `tracks.json` для той
же библиотеки) ничего не сломает — новые треки добавятся, пропавшие
пометятся как отсутствующие, остальное просто обновит дату.

---

## 6. Определить жанры

```powershell
go run ./cmd/music enrich run
```

Пройдётся по всем исполнителям библиотеки (у кого ещё нет жанра или
кэш устарел), спросит Last.fm и запишет результат в базу. На первый
раз, если исполнителей много, может занять время — есть пауза между
сетевыми запросами (чтобы не выглядеть как атака на чужой сервер).
Можно ограничить прогон для пробы:

```powershell
go run ./cmd/music enrich run --limit 20
```

Повторный запуск не тратит новые запросы на уже обработанных
исполнителей — ответы кэшируются на 30 дней.

Посмотреть, что получилось:

```powershell
go run ./cmd/music genres tree     # дерево жанров со счётчиком треков
go run ./cmd/music stats           # сводка по библиотекам
```

---

## 7. Получить отфильтрованный список

Ради этого всё затевалось:

```powershell
go run ./cmd/music filter rock --library "Имя библиотеки"
```

Печатает таблицу: исполнитель, трек, длительность, уверенность —
отсортировано от самых уверенных совпадений. Код жанра — из дерева
жанров (`music genres tree`): `rock`, `metal`, `hip_hop`, `pop` и так
далее. Поджанры попадают в выдачу автоматически — `rock` заодно
приносит `punk_rock`, `hard_rock`, `grunge` и всё остальное дерево
под ним.

Если жанр слишком узкий фильтр отсекает лишнее (или наоборот,
пропускает мусор) — подкрути порог уверенности:

```powershell
go run ./cmd/music filter rock --library "Имя библиотеки" --min 0.30
```

Получить список в файл вместо экрана — обычное перенаправление шелла,
отдельной команды экспорта для этого нет:

```powershell
go run ./cmd/music filter rock --library "Имя библиотеки" > рок.txt
```

## Если что-то не работает

- **`dial tcp ... connection refused`** на любой команде `music ...` —
  база не поднята. Смотри шаг 4.
- **`Ошибка: lastfm: доступ к API запрещён (error 11)`** на `enrich
  run` — геоблокировка Last.fm, включи VPN (см. шаг 0 и Р-017 в
  `docs/DECISIONS.md`).
- **`filter` ничего не находит** — сначала проверь `music library
  list`: не разъехалось ли название библиотеки регистром букв (см.
  шаг 5). Если библиотека верная — возможно, `enrich run` для неё ещё
  не запускался (`music stats` покажет, у скольких исполнителей вообще
  есть жанр), либо порог `--min` слишком высокий.
- **Расширение перестало находить треки** — см. раздел «Если однажды
  перестанет находить треки» в [extension/README.md](../extension/README.md).
